# ⚡ Персональный трекер расписания «Под ключ» + Умный Telegram-бот

## 🌟 Ключевые возможности

- 🌐 **Интерактивный веб-трекер (`index.html`):** стильный темный дашборд, фильтры по категориям (Спорт, Учеба, Еда, Сон, Дела), прогресс-бары и автоматическое сохранение.
- 🤖 **Telegram-бот с кнопками:** интерактивные чекбоксы `[⬜] / [✅]`, нажимаемые прямо в чате на телефоне.
- 🔄 **Кросс-девайс синхронизация:** галочка, нажатая на телефоне в Telegram, сама появляется на мониторе ПК через 3 секунды.
- 🔔 **Умные Push-напоминания по времени:**
  - `07:30` — утренний брифинг (пары, тренировка, напоминание о форме и ланчбоксе);
  - `за 40 мин` — сигнал о выезде в университет;
  - `19:00` — напоминание о батч-кукинге на 2 дня (Ср, Пт, Вс);
  - `23:00` — сигнал ко сну (отбой строго в 23:30).
- ⚖️ **Трекер веса и динамики сушки (`/weight`):** расчет чистого сброса жира за неделю и прогресс до цели 85.0 кг.
- 📝 **Дневник рабочих весов в зале (`/log`):** память весов перед следующей тренировкой для прогрессивной перегрузки.
- 🛒 **Интерактивный список продуктов (`/groceries`):** чек-лист для похода в супермаркет.
- ⚙️ **Алгоритмический компилятор расписания из JSON (Без ИИ):** отправьте боту `КОНСТРУКТОР_РАСПИСАНИЯ.json`, и он за 0.05 сек перестроит всю жизнь на 4 недели вперед!
- 🎙️ **Голосовое управление (Voice):** возможность наговаривать дела голосом на ходу.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлен [Node.js](https://nodejs.org/) (версия 18+).  
В папке проекта перейдите в `bot` и установите пакеты:
```bash
cd bot
npm install
```

### 2. Настройка окружения
В папке `bot` скопируйте `.env.example` в `.env` и укажите ваш токен бота:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
PORT=3000
```

### 3. Запуск
- На Windows: просто дважды кликните по файлу **`Запустить_Бота_и_Синхронизацию.bat`**.
- Либо через терминал:
```bash
cd bot
node server.js
```
